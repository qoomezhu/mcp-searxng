mcp-searxng · Netlify 适配版

这个分支把原始的 Go MCP 服务器改造成了 Netlify Functions 版本，默认以 stateless + JSON response 模式运行。

可用端点

  • /mcp → MCP 主入口
  • /health → 健康检查
  • /.netlify/functions/mcp → Netlify 函数直连入口

部署前需要配置的环境变量

  • SEARXNG_URL：必填，SearXNG 实例地址
  • AUTH_USERNAME / AUTH_PASSWORD：可选，SearXNG Basic Auth
  • USER_AGENT：可选，自定义抓取 UA
  • ALLOW_PRIVATE_ADDRESS：可选，默认 false

本地调试推荐使用 netlify dev。
